# 领域文档

## 探索代码前阅读

- 根目录 `CONTEXT.md`
- 与当前工作相关的 `docs/adr/` 决策

如果文件尚不存在，直接继续工作，不要求提前创建。

## 使用领域语言

Issue 标题、测试名称、设计说明和重构提案必须使用 `CONTEXT.md` 中的规范术语。不要使用 glossary 明确标记为应避免的近义词。

如果发现术语缺失，记录给领域建模流程，不要自行创造近义词。

## 布局

本项目采用单上下文布局：根目录 `CONTEXT.md` 加 `docs/adr/`。

## ADR 冲突

如果新决策与已有 ADR 冲突，必须显式指出，不能静默覆盖。
