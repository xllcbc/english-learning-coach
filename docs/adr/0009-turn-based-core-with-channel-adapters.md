# agent 核心是回合制，文本与语音只是通道适配器

## 背景

Teacher Conversation（文本）与 Speaking Practice（语音）都是多轮对话。若各自实现一遍决策循环，会重复逻辑、无法并行、也难以共享工具与溯源。需要把「脑」与「口」分离。

## 决策

1. **回合制核心。** 核心接收一个 Turn、产出一个 Turn；一个 Turn 可包含多个 Agent Step。
2. **通道适配器。** 文本通道走 SSE（复用现有讲解的流式与回放）；语音通道走 WebSocket（STT 输入、TTS 输出）。
3. **barge-in 在通道层。** 打断、取消播放、音频缓冲都由通道层处理，不进入核心。
4. **核心不感知通道类型。** 核心只依赖 Turn 与工具注册表。

## 与既有 ADR 的关系

- **ADR-0002（结构化纠错与流式讲解分离）**：不变。本 ADR 只把「流式」抽象成通道能力，讲解链路不受影响。
- **ADR-0008（工作流 vs agent）**：本 ADR 只描述 agent 场景的运行时形态；工作流场景不经过此核心。

## 后果

- A 与 D 可以并行开发、共享同一核心；语音失败可降级为文本通道（见 ADR-0011）。
- 通道层各自处理传输、重连与播放，核心保持简单、可测。
